# WusicPlayer 使用指南

> 面向最终用户与开发者的人机交互说明.

## 1. 界面布局

```
┌────────────────────────────────────────────────────────┐
│ 菜单栏 (File / View / Playback / Settings / Help)      │
├──────────────────────┬─────────────────┬───────────────┤
│ 播放列表树 (Playlist)│ 歌曲表          │ 侧边面板      │
│ 媒体库浏览 (Library) │ (当前播放列表)  │ (封面 / 歌词) │
├──────────────────────┴─────────────────┴───────────────┤
│ 底部控制栏 (播放/进度/音量/模式/设备)                  │
└────────────────────────────────────────────────────────┘
```

- **左侧 (上)**: 播放列表树 - 管理播放列表
- **左侧 (下)**: 媒体库浏览 - 浏览/搜索音乐库
- **右侧**: 当前播放列表歌曲表
- **底部**: 播放控制栏
- **侧边**: 当前曲目信息 (封面 / 元数据 / 歌词) 

## 2. 播放列表树

### 基本操作
| 操作             | 行为                                |
|------------------|-------------------------------------|
| 单击             | 选中该列表                          |
| 双击             | 切换到该列表 (右侧歌曲表随之变化)   |
| 再次单击已选中项 | **内联重命名** (类似于 KDE Dolphin) |
| 拖动 (单选)      | 重排列表顺序                        |

### 右键菜单
- **列表项上**: 
  - `New Playlist` - 新建列表
  - `Add track` / `Add folder` - 导入文件/文件夹到该列表
  - `Save as` / `Rename` / `Copy & Paste` / `Remove`
- **背景处**: 仅 `New Playlist`

## 3. 歌曲表 (当前播放列表) 

| 操作              | 行为                                 |
|-------------------|--------------------------------------|
| 单击              | 选中行                               |
| 双击              | 播放该曲目 (并定位/高亮)             |
| 拖动 (单选/多选)  | 拖到播放列表树 -> **复制到目标列表** |

### 右键菜单
- **单选**: `Play` / `Remove` / `Remove Missing Tracks` / `Add to Playlist...` / `Open in file explorer` / `Property`
- **多选**: `Remove Selected` / `Add to Playlist...`
- **表头**: `Insert Column Here` / `Remove This Column`
- 分组节点前有展开/收起箭头 (组节点本身不提供曲目操作) 

## 4. 媒体库浏览

- 顶部: 分类下拉 (艺术家/专辑/流派/文件夹/年份/无) + 搜索框 + 配置按钮
- **双击**: 曲目 -> 直接播放；分组节点 -> 展开/折叠

### 右键菜单 (曲目或分组上) 
`Play` / `Add to Playlist...` / `Refresh Library`

### 拖拽
| 源                  | 目标       | 行为                 |
|---------------------|------------|----------------------|
| 曲目 (单选)         | 播放列表项 | 添加到该列表         |
| 曲目 (单选)         | 歌曲表     | 添加到当前列表       |
| 分组节点            | 同上       | 该组全部曲目批量添加 |
| 多选 (全组或全曲目) | 同上       | 批量添加             |
| 多选 (组+曲目混合)  | -          | 无效，日志提示       |

## 5. 搜索

### 媒体库搜索 (媒体库浏览的搜索框)
- SQLite FTS5 全文搜索
- **支持前缀匹配与子串匹配** (CJK 友好)
  - 以 `夢消失　〜 Lost Dream` 为例
  - 输入 `夢消` 可命中 `夢消失　...`
  - 输入 `Lost` 或 `Los` 可命中 `Lost Dream`
  - 输入 `ost` (子串) 也能命中
- 多词: 空格分隔，全部命中 (AND)
- 双击结果 -> 直接播放

### 播放列表内搜索 (Ctrl+F)
- 独立浮动窗口，搜索当前播放列表 (内存索引，实时过滤)
- 双击结果 -> 播放并**同步定位**到主窗口歌曲表与信息面板

## 6. 快捷键 (默认)

| 快捷键         | 功能                |
|----------------|---------------------|
| `Space`        | 播放 / 暂停         |
| `S`            | 停止                |
| `Ctrl+O`       | 导入文件到当前列表  |
| `Ctrl+Shift+O` | 加载播放列表文件    |
| `Ctrl+S`       | 保存当前播放列表    |
| `Ctrl+F`       | 打开搜索面板        |
| `Ctrl+L`       | 显示 / 隐藏桌面歌词 |
| `Ctrl+,`       | 打开设置            |

快捷键可在 **Settings -> Shortcuts** 中自定义. 

## 7. 设置 (Settings)

- **Media Library**: 管理被监控的音乐文件夹 (添加/移除) ，设置"添加未入库文件时"的策略
- **Lyrics**: 歌词显示选项
- **Theme**: 选择系统/内置/外部插件主题
- **Shortcuts**: 自定义快捷键

## 8. 配置文件

`~/.config/WusicPlayer/WusicPlayer.json`

保存: 窗口布局、播放设置、播放列表缓存引用、歌曲表头状态、媒体库浏览状态、搜索面板状态、快捷键绑定、桌面歌词设置、添加文件策略等. 

## 9. 常见问题

- **Wayland 下部分效果异常**: 自定义标题栏等依赖 X11/XCB 的功能在 Wayland 下可能不完整. 
- **搜索无结果**: 媒体库为空或未添加被监控目录 (见 Settings -> Media Library).
